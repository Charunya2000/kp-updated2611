  Background:
    Given the following input files are available:
      | File No. | File Name               | Description                    |
      | File 1   | RCNO file               | Current month RECON file       |
      | File 3   | Membership system file  | Kaiser membership data         |
      | File 5   | 834 file (last 30 days) | Recent enrollment transactions |
      | File 6   | Last month RCNA file    | Prior RCNA file                |
    And the columns in all files start as "Column 1", "Column 2", etc.
    And all input column values are trimmed, converted to uppercase, and control characters are removed


CRITICAL RULES (DO NOT VIOLATE):

1. DO NOT infer, drop, rename, reorder, or merge columns.
2. Read ALL columns, including:
   - empty columns
   - sparsely populated columns
   - columns with placeholder values
3. Ignore Excel formatting, filters, hidden rows, cell styles, comments, and formulas.
4. Treat the first row as the ONLY header row.
5. Preserve column order exactly as defined in the schema below.
6. Treat ALL column values as STRING (no type inference).
7. Empty cells must be returned as empty strings ("").
8. Do NOT perform validation, cleansing, or enrichment during ingestion.
9. If a column has no data in any row, it MUST still appear in the output.
10. If any column is missing, HALT and return an explicit error listing the missing columns.


- Ignore any outputs, variables, or assumptions from previous runs
- Do not reuse derived values unless they are explicitly provided in the current input
- Treat this run as stateless
